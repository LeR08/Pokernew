# Spots de référence TexasSolver / TexasSolver reference spots

Chaque spot existe en deux formats : `<nom>.txt` (fichier de commandes de TexasSolver, version console) et `<nom>.json`
(notre `SpotConfig`). Les arbres sont simples et construits pareil des deux côtés : à chaque street, une taille de mise ou tapis, et la seule
relance possible est le tapis.

Each spot exists as `<name>.txt` (TexasSolver console command file) and `<name>.json` (our SpotConfig), with the same simple tree (one bet size or all-in, all-in raises only).

- `1-river-polar` : board Td9d6hQc2s, pot 20, tapis 90, mise 50 % du pot
- `2-river-small` : board Ks8d5c3h2s, pot 10, tapis 40, mise 75 % du pot
- `3-turn` : board Td9d6hQc, pot 20, tapis 90, mise 50 % du pot
- `4-flop-spr3` : board QsJh2h, pot 20, tapis 60, mise 50 % du pot
- `5-flop-3bp` : board AhKd7s, pot 20, tapis 90, mise 33 % du pot
